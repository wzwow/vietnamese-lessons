# Pronunciation-guide conventions

The `ro` / guide fields are rough English respellings of **Northern (Hà Nội)** Vietnamese. Add a Southern variant only where it really differs, written as `zahn (North) · rahn (South)`.
Reuse the exact guide that an earlier lesson or `reference/common-words.html` already uses for a word. Search the repo before inventing a new one.

## Consonants
| Letter | Guide | Examples |
|---|---|---|
| c / k / q | **g** in most words (soft, unaspirated k). Lesson 3 explains this. Keep the established exceptions: cà phê = kah fay, cay = kigh, cơm = kuhm, quá = kwah, cuối = kwoy | cái = gai, có = gaw, con = gawn, cảm ơn = gahm uhn, của = goo-uh, công ty = gohng tee, cửa = guh-uh, cân = guhn |
| kh | **kh** (breathy). Never plain k | không = khohm, khỏe = khweh, khi = khee |
| d / gi / r | **z** (North) | gì = zee, giờ = zuh, rồi = zoy, rất = zuht, rưỡi = zuh-uh-ee, rẻ = zeh |
| đ | **d** | đi = dee, đâu = dow, đá = dah |
| tr / ch | **ch** | trà = chah, trăm = chahm, chị = chee |
| th | **t** (breathy) | thư = t'uh, thêm = taym, thứ = tuh |
| x | **s** | xin = sin, xem = sem |
| ph | **f** | phở = fuh |
| nh | **ny** at the start, **ng** at the end after i | nhà = nyah, sinh = sing, tính = ting |
| ng / ngh | **ng** | ngon = ngawn, nghìn = ngeen, người = nguh-uh-ee |

|---|---|---|
| a | ah | ba = bah, là = lah |
| ă | a (short) | ăn = an, năm = nahm, lăm = lahm |
| â, ơ | uh | sâm = sum, ơn = uhn, mở = muh, giờ = zuh |
| e | eh | xem = sem, mèo = meh-oo, rẻ = zeh |
| ê | **ay** | phê = fay, tên = tayn, vệ = vay, đêm = daym, thế = tay |
| i / y | ee | đi = dee, ly = lee |
| o | **aw** | có = gaw, ngon = ngawn, món = mawn, bò = baw |
| ô | oh | một = moht, tô = toh, bốn = bohn |
| u | oo | phút = foot, lúc = look |
| ư | uh | thư = t'uh, sữa = suh-uh |

| âu | ow | đâu = dow |
| ôi | **oy** | tôi = toy, rồi = zoy, tối = toy |
| ơi | uh-ee | trời = chuh-ee, chơi = chuh-ee |
| ươi / ười | uh-uh-ee / uh-ee | mươi = muh-uh-ee, mười = muh-ee, người = nguh-uh-ee |

## Other rules
- Write the guide in lower case with the sentence's punctuation, e.g. `sin chow, toy lah ming`.
- Tone marks are not shown in guides. The notes explain tones.
- After any change, check that the same word has the same guide in every lesson (`rg` for the word) and run `npm run qa`.
